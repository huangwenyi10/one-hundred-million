# 抖音平台合规规范（发布抖音前必读 · 固定规范第 30 条配套）

> 适用：本技能所有**以抖音为发布目标**的成片（作者默认发布渠道之一）。
> 核实日期：2026-09-13。**平台规则变动频繁，本文件是「已知红线的固化清单」，不是官方规则原文**——每期开工前如涉及新品类/新话术，须回官方渠道复核（见 §10）。

| 级别 | 含义 | 本文件中的使用方式 |
|---|---|---|
| **L1 官方原文** | 抖音开放平台文档 / 抖音官方治理公告 / 抖音黑板报 / 抖音电商·生活服务官方公告、国家网信办文件 | **硬门禁**：命中即改，不改不发布 |

## 1. 技术规格（上传能否通过 / 画质是否被压）

### 1.1 开放平台 API 一键发布（L1 · open.douyin.com 官方文档）

| 项 | 要求 | 级别 |
|---|---|---|
| 文件大小 | 视频 **≤ 4 GB**；图片 ≤ 100 MB | L1 |
| 视频时长 | **≤ 15 分钟** | L1 |
| 格式 | 常用格式，推荐 **mp4 / webm** | L1 |
| 品牌水印 | **带品牌 logo 或品牌水印的视频，会命中审核逻辑，有较大概率导致推荐降权 / 下架 / 封号** | L1 |
| 审核口径 | 与抖音端内拍摄上传一致 | L1 |

> **对本技能的直接影响（重要）**：
> 1. 读书训练营单部 **≥ 30 分钟 > API 硬上限 15 分钟** → **无法通过开放平台接口发布**，只能人工走 App / 网页端上传（网页端时长上限以账号实际权限为准），或按既有第 17 条派生切条后分段发布。**不得描述成一键发布已成功**。
> 2. 「带品牌水印 → 降权/下架」这条与本技能既有规则一致但更硬：**画面中所有第三方平台水印、下载源角标、无关品牌 logo 必须清干净**（既有固定规范第 14 条 + Quality Gates「图示无侵权元素」继续适用，此处加一条抖音侧后果说明）。

### 1.2 网页端 / App 上传的建议参数（L4 · 第三方多源一致，非官方原文）

| 项 | 建议值 |
|---|---|
| 格式 / 编码 | mp4、H.264（兼容性最好） |
| 分辨率 | 横屏 **1920×1080**；竖屏 1080×1920（≥720p 是底线） |
| 帧率 | 25 / 30 / 60 fps（本项目成片 30 fps，符合） |
| 码率 | **不低于 516 kbps**（本项目成片远高于此） |
| 音轨 | AAC-LC，采样率 ≥ 44.1 kHz |
| 单文件大小 | 网页端上限 10 GB（L4，与 API 的 4 GB 不同，勿混用） |
| 时长上限 | 随账号权限分级（1 / 3 / 5 / 15 分钟乃至更长），**以「创作者服务中心 → 长视频权限」实际显示为准**；**不得假设账号已有对应时长权限** |

**本技能成片默认参数（1920×1080 / 30fps / mp4 / 高码率）天然满足上述建议值**，无需为抖音单独重编码——除非作者指定竖屏。

### 1.3 时长权限（L4 · 不确定项，必须实机核对）

- 第三方文章对「长视频权限」的开通门槛（粉丝量、认证状态）说法互相矛盾，**不予采信、不写入口播或对外承诺**。
- 唯一可靠口径：**发布前在创作者中心实际查看本账号可发布的最长时长**；若成片超过该时长，走「派生切条 + 分段发布」或降档重制。

## 2. 发布必选标签（2026 新规 · 硬门禁）

### 2.1 平台必选标签（L1-2 · 中央网信办规范短视频内容标注，央视新闻报道，2026）

- 平台必须提供 **6 类必选标签**：`含有虚构演绎内容` / `含有AI生成内容` / `含有营销信息` / `内容为转载` / `内容为个人观点` / `无需标注`。
- **内容标注是发布必经环节**：必须选一项才能发布。未规范标注的存量内容会被分批回溯补标或纠正。

### 2.2 抖音 AI 标识要求（L1 · 抖音黑板报《抖音内容标识使用规范》2026-05 + 《人工智能生成合成内容标识办法》2025-09-01 施行）

- 使用平台 AI 特效或**第三方 AI 工具生成的内容，应添加「内容由AI生成」标识**；发布时须**主动勾选/声明**，未声明会被平台核验后补标，且漏标属可治理项。
- **禁止恶意删除、篡改、伪造、隐匿生成内容标识**；不得删除文件元数据。

### 2.3 本技能的默认映射（每个视频都必须逐项确认）

| 标签 | 本技能默认 | 判定依据 |
|---|---|---|
| 含有AI生成内容 | **必选** | 配音为 TTS（`zh-CN-YunxiNeural`），画面为脚本/HTML 渲染生成 |
| 含有营销信息 | **默认必选** | 训练营获客向内容、含引导关注/咨询的 CTA |
| 内容为个人观点 | 按实情 | 口播为作者个人判断/经验时勾选 |
| 含有虚构演绎内容 | 一般不选 | 本技能禁止编造（固定规范第 7 条）；若为演示用虚构案例须选 |
| 内容为转载 | 仅当整条为转载时 | 本技能为原创，通常不选 |
| 无需标注 | **不用** | 该标签仅适用于真实生活记录类，本技能不属于 |

**画面侧执行**：AI 显式标识与既有「左上角水印 `作者：@Map`」**不得重叠**；如需画面内加「AI 生成」字样，放**右上角或右下角固定小字**（避开左上水印区与底部字幕带），且**不得遮挡画面内容**（既有第 5/15 条继续适用）。

## 3. 内容红线（禁发 · L1 抖音社区自律公约 + 抖音创作者内容规范）

以下内容一律不碰，命中即本次不发布：

1. **危害国家及社会安全**：反对宪法确定的基本原则；危害国家安全、泄露国家秘密；损害国家形象；煽动民族仇恨/歧视；违背破坏宗教政策、宣扬邪教与封建迷信、伪科学；煽动非法集会游行示威。
2. **违法犯罪行为**：宣扬暴力、恐怖、极端主义；歪曲丑化英雄烈士；淫秽色情赌博毒品凶杀恐怖教唆犯罪；伪造/出售/恶搞人民币；违法募捐；斗殴霸凌；诈骗传销走私；违法销售禁限商品。
3. **危及未成年人**：涉未成年人色情低俗、侵害其身心/财产/人格/隐私；过度消费未成年人；煽动饭圈互撕、无底线追星打榜。
4. **危险行为**：厌世轻生等悲观消极内容；自残自虐自杀演示；美化自我伤害或饮食障碍；血腥暴力惊悚引人不适内容。
5. **不合规医疗内容**：非认证用户不得以医生名义发布疾病预防/诊断/治疗/用药；不得宣传推拿按摩刮痧拔罐具治疗功效。
6. **侵犯人身权益**：侮辱诽谤、造谣、骚扰恐吓、**人肉搜索与网络暴力**（含教唆、鼓动、传播网暴内容）。
7. **隐私与安全（L2）**：不得出现手机号、微信号、具体地址、二维码等泄露隐私或危害人身/财产安全的元素。
8. **政治引导（L2）**：不得涉政治敏感信息或社会负面/时事热点事件；不得涉国家领导人、公检法军、国家工作人员、政治名人、革命烈士、国家机关单位、国家政策。
9. **公序良俗（L2）**：不得涉不良习惯（抽烟/脏话）、不文明行为、不正确价值观；不得炫富、歧视、引战、整蛊恶搞虐待。
10. **国家标志（L2）**：不得使用或变相使用国旗、国歌、国徽、军旗、军歌、军徽等国家标志性内容进行商业宣传。

> 技术训练营的常规选题基本不触及 1~6、8~10；**真正的高危区在第 4 节（话术）与第 5 节（引流）**。

## 4. 话术红线（技术训练营最易踩 · 硬门禁）

来源：L2 巨量星图《抖音短视频内容制作规范》+ L1 抖音电商《教培虚拟类商品专项治理公告》+ L1 抖音生活服务《教育培训类目专项治理公告》。**本技能讲「技术 + 变现 + 1 亿目标」，是这三条规则的重叠高危区，必须逐条过。**

### 4.1 绝对化用语（禁）

- **禁用**：最好 / 第一 / 唯一 / 全网最 X / 顶级 / 极致 / 绝对 / 万能 / 100% / 国家级 / 世界级 / 永久 / 无敌 / 天花板…
- **改写**：改为可核验的比较口径——「在我们实测的 3 个版本里，这个方案吞吐最高」而非「性能最好」；说不出比较范围的，直接删。

### 4.2 效果与收益承诺（禁 · 本项目最高危）

- **禁用**：保证学会 / 包教包会 / 包过 / 必过 / 包就业 / 包涨薪 / 学完就能拿高薪 / **学习本课程可以月入过万** / 做一天（月/年）赚多少钱 / 投资一个月肯定回本 / 稳赚不赔 / 零基础速成。
- 官方公告已把「用这套方法，普通人也能月入过万」**原文列为例**——**本技能涉及「1 亿目标 / 变现 / 高客单」的内容必须严格规避收益承诺**。
- **豁免**：**客观描述行情、价格、单价**（不做时间段收益保证）不违规。→ 可以讲「这个岗位市场报价区间是多少」，不可以讲「学完你就能拿到这个价」。
- 正确姿势：**只讲机制、只讲可核验的事实与来源**——「某公司公开的技术方案把查询从 74 秒降到 2.3 秒（来源：XX 官方文档）」而不是「学会这个你也能涨薪」。

### 4.3 教培虚拟内容专项（L1）

- 不得宣称课程/资料**永久、终身、长期无限次免费**有效；有效期宣传须与详情页一致且**不超过 5 年**。
- 不得暗示有密押卷、押中原题、内部/小道消息、命题组资源。
- 不得过度承诺学习效果或高收益（如「期末稳上 XX 分」「粉丝量暴涨 XX」）。
- **不得引导用户到站外加联系方式或私下二次缴费**（与第 5 节联动）。

### 4.4 其它话术红线

- **不得制造焦虑**：不贩卖升学焦虑、职业焦虑、35 岁危机式恐吓；不「旧闻新炒」；不炒作排名。
- **不得贬低同行**：踩一捧一、踩多捧一均禁止。
- **不得虚假资质**：无资质不得自称「专家 / 名师 / 命题老师 / 阅卷专家 / 教育规划专家」；账号昵称与简介**不得滥用「大学 / 学院 / 名校 / 官方 / 独家」等权威词汇**（本技能第 14 条已禁「训练营名 + 期号」入画面，此处进一步约束账号资料与口播自称）。
- **不得无法考证的话术**：「知名机构认证」「最新发明」「纯天然」「无副作用」等。
- **不得诱导互动**：不得诱骗完播、道德绑架式求赞/求关注（既有 CTA 规则继续适用，但措辞不得越界）。
- **不得搬运**：非原创、搬运他人内容、非本人素材简单加工一律禁止（本技能全流程为原创生产，天然满足）。

## 5. 引流红线（本技能 CTA 必须站内收敛 · 硬门禁）

### 5.1 禁出现的内容（口播 / 字幕 / 标题 / 封面 / 背景板 / 画面任意位置）

微信 / 加我 / 加 V / VX / 薇信 / 企微 / 企业微信 / QQ / 电话 / 手机号 / 二维码 / 扫码 / 私域 / 私聊领资料 / 站外链接 / 网盘链接 / 网址。

- 平台 AI 会对上述关键词实时识别，**识别到站外引流意图会分层处罚：首次限流降曝光 → 多次限制直播与商品上架等变现功能 → 严重者永久封禁**。
- 教育培训类目更有专项治理：**经核查存在违规引流至站外，可强制下架商品、限制发布权限、限制直播与投放、冻结或扣罚货款，直至清退**。

### 5.2 合规 CTA（改后可用）

| 允许 | 说明 |
|---|---|
| 关注 / 点赞 / 收藏 | 纯站内互动，安全 |
| 评论区提问 | 引导站内讨论 |
| 「有需要可以私信我」 | **只引导站内私信，不提任何站外渠道** |
| 「主页有更多 XX 内容」 | 站内主页导流，安全 |

**与总纲表述的冲突处置**：总纲「CTA 不只涨粉，而是筛选出有付费/合作意愿的观众」「引导私域/咨询」是**商业意图描述，不是话术授权**——落到口播、字幕、画面、文案上的 CTA **一律以本站内清单为准**；两者冲突时以 `douyin-compliance.md` 为准。

## 8. 发布路径与设置清单（Step 8 执行用）

1. **判断时长是否超限**：成片时长 > 15 分钟（如读书营 ≥30 分钟）→ **不可走开放平台 API**，走人工上传；同时核对创作者中心显示的账号可发布上限。
2. **人工发布路径**：`creator.douyin.com`（网页端）→ 登录 → 发布作品 → 上传成片 → 填标题/话题/封面。
3. **发布页必做勾选**：AI 生成内容标识（本技能默认必勾）+ 平台必选标签（默认「含有AI生成内容」+「含有营销信息」）。
4. **封面**：用 Step 6 产出的封面图，不自选随机帧。
5. **文案自检**：标题/正文/话题过一遍 §4 话术红线 + §5 引流红线（脚本可代跑，见 §9）。
6. **画质**：不开启「智能优化画质」类自动压缩，选择高清发布（L4 建议）。
7. **不做发布后立刻大改标题/封面**（改动会重新过审，可能影响已获推荐）。
8. **归档**：发布后按既有第 19 条归档百度网盘，并在日志记录所用标签组合。

## 9. 自动化自检（脚本 · 强制）

```
python3 scripts/douyin_compliance_check.py <口播稿.txt> [--title "标题"] [--copy 发布/*.md ...] [--json]
```

- 扫描**站外引流词 / 绝对化用语 / 效果收益承诺 / 焦虑对立词 / 教培虚拟内容禁语 / 固定收尾句 / 训练营标识与期号**。
- 输出分级：`BLOCK`（红线，必须改，exit 1）与 `WARN`（疑似，建议人工确认，不阻塞）。
- **exit 0 才允许进入 Step 7 作者审核**；命中 `BLOCK` 一律改写话术 → 重新生成配音与字幕 → 重跑脚本。
- 脚本为**本地确定性扫描**（正则 + 词表），不依赖 `REDFOX_API_KEY`；`multi-wordcheck` 仍作为可选的三平台官方词库补充（既有 Step 7 第 1 条不变）。
