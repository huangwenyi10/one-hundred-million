# 训练营体系化目录骨架（书目录式 · 看完成为专家）

## 使用说明

- 每个训练营 = **一本体系化教材**，本文件是这本教材的**目录**；每一条短视频 = 目录中的**一节**，不是孤立知识点。
- 编号规则：`<章>-<节>`，如 `03-2` = 第 3 章第 2 节。进度记入 `one-hundred-million-syllabus.json` 的 `done` 列表。
- **顺序推进**：默认按目录顺序往下讲，保证体系完整；允许因热点/时效提前讲某一节，但须记录，**不得**长期滞留前几章、不得整章跳过。
- 一章可拆多节，一节 = 一条视频；若某节内容量大，可拆为 `03-2a` / `03-2b` 连续两条。
- **目录是骨架，不是牢笼**：目录解决「讲什么」，热点/案例解决「怎么讲得有人看」——用当期的真实案例、数据、热点去讲体系中固定的那一节。
- 目录骨架可在实践中增补章节（新章追加在末尾，不插队打乱既有顺序），增补时同步更新本文件与进度文件。

## 9. 读书训练营

**专家目标**：把经典书籍读透、讲清，用一本书构建一整套认知体系。

**特殊说明**：读书训练营**天然体系化**——书本身就是目录，无需另设骨架。它遵循 SKILL.md「读书训练营专项」的**「一书三分」模型**：一本书拆上 / 中 / 下三部，按书中章节顺序推进，每部拆 2–3 条选题。

- 进度载体：`reading_camp_progress.json`（`currentBook` / `partsDone` / `finishedAt`）。
- 换书时，新书从「上部」重新开始，形成新的体系线。
- 与其余 8 类的差别：其余 8 类用本文件的目录骨架推进，读书训练营用**原书目录**推进；两者都要求「顺序推进、不跳部/不跳章」。
