# 内容档位规范（S / M / L 三档）

每支视频开工前必须先定档。档位决定口播稿字数、结构、画面页数与停留节奏。**账号内容结构按 70% S / 20% M / 10% L 配比**，S 档负责破圈涨粉，M 档建立信任，L 档沉淀口碑与私域转化。

## 档位总表

| 档位 | 时长 | 口播稿字数（按 260 字/分钟） | 画面页数 | 单页停留 | 主要作用 |
|------|------|------------------------------|----------|----------|----------|
| **S 档** 破圈款 | 60–90 秒 | 250–400 字 | 6–10 页 | 5–8 秒 | 拿推荐流量、涨粉 |
| **M 档** 中深度 | 3–5 分钟 | 750–1300 字 | 12–20 页 | 10–15 秒 | 建立专业信任 |
| **L 档** 长课 | 15–30 分钟 | 3800–7600 字 | 20–40 页 | 25–45 秒 | 口碑沉淀、训练营引流 |

## S 档（60–90 秒）结构模板

1. **前 3 秒钩子**（口播 + 封面画面双钩子，20–30 字）：反常识 / 数字冲击 / 痛点提问，见 `hooks-and-cta.md`。
2. **单点结论**（30–50 秒）：**只讲一个结论**，不铺垫背景、不展开原理。给一个数据或一个反差事实。
3. **一句为什么**（15–25 秒）：用大白话解释一句原因，点到为止。
4. **CTA**（5–10 秒）：引导关注 / 看合集 / 评论区互动，见 `hooks-and-cta.md`。
5. 结尾自然收尾（无固定结束语模板，禁止"以上就是今天所有内容，感谢大家观看，我们下期再见"类收尾）。

S 档硬性要求：不出现"背景/现状/架构演进"这类铺垫段；不出现三个以上并列论点；画面字号比 L 档大 30%；每页不超过 12 个字 + 1 个数字。

## M 档（3–5 分钟）结构模板

钩子（3s）→ 痛点/背景（30s）→ 方案或原理（90s）→ 一个数据或案例验证（60s）→ 结论 + CTA（30s）→ 结尾自然收尾（无固定结束语模板）。

允许一个展开段落，但并列论点不超过 3 个；案例只讲 1 个，讲透。

## L 档（15–30 分钟）结构模板

沿用原有通读式结构：背景/痛点 → 现状方案及问题 → 转折点 → 新方案（架构/原理） → 数据验证 → 用户案例 → 总结展望 → CTA → 结尾自然收尾（无固定结束语模板）。

每隔 1–2 分钟必须埋一个钩子维持完播（提问、悬念、转折、"划重点"提示）。

## 档位与训练营的搭配

| 训练营 | 主力档位 | 说明 |
|--------|----------|------|
| 架构师 / 大数据 / AI | S 为主，M 为辅 | 热点多、可绑定新闻与行业事件 |
| 前端 / 测试 | S + M | 新特性、踩坑、性能对比适合短平快 |
| 产品 / 管理 / 软技能 | S 为主 | 情绪共鸣型内容最容易破圈，优先 S 档 |
| 长课 / 训练营导流 | L | 完整方法论、体系课，引流私域 |

## 矩阵分号策略（涨粉规模化的关键）

同一套内容按训练营拆到不同账号发布时：S 档内容可跨号复用（改封面配色与开场话术即可），M/L 档只在对应垂类号发布。每个号固定一套主题色（见 SKILL.md 训练营主题色表），形成视觉锤。
